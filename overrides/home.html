The problem

Search engines match topics. Applications fail on rules.

Fragmented sources

Funding is published on thousands of university, government and foundation websites, and no single portal covers them.

Eligibility decides

Nationality, career stage, host country and deadline decide whether you can apply. Relevance alone does not.

Errors are costly

A wrong deadline or a misread nationality rule wastes weeks. Every fact we show must be checkable.

How it works

Language models read and judge. Code decides.

  1. 0

    Build the library

    Agents crawl official funder sites, extract each programme with a quote for every rule, and three judges from three companies verify each claim.

  2. 1

    Understand you

    A short form becomes a structured profile. Fixed facts are taken as given; research fields are inferred locally.

  3. 2

    Match and filter

    Keyword and meaning-based search are fused by rank, then plain code tests every eligibility rule, line by line.

  4. 3

    Rank and explain

    Eligible programmes are ranked by fit, with the evidence, deadlines and an application plan on request.
