# ACCESS documentation

Source of the ACCESS companion site: **https://vishram0905.github.io/access-docs/**

ACCESS (AI-Curated Constraint-Aware Eligibility & Scholarly Search) is a multi-agent system that finds research
funding a researcher is eligible for, with every stated condition traced to the funder's own page.
GP8000 / GP8001 AI Literacy · Cohort C · Group 5.

This repository holds the documentation only (Markdown pages, built with MkDocs Material).

```bash
pip install -r requirements.txt
mkdocs serve        # preview at http://127.0.0.1:8000
mkdocs gh-deploy    # publish to GitHub Pages
```
